# Block Entity Claude Skill

A Claude skill for building Minecraft bosses, mobs, items and props out of vanilla block displays (no resource pack), from a picture or a short prompt. Made for the CBosses and CQuests plugins.

## Install

Download `block-display-bosses.zip` from the latest release and upload it in Claude under Settings → Capabilities → Skills, or copy the `block-display-bosses` folder into your skills folder.

## What it covers

- Making the in-game model match the preview (correct display transforms)
- Clean colours, simple minis, real limbs
- Grow-in entrances with theme particles
- Faces, idle animations, sizing and hitboxes
- Roster, removing bosses, and the build and release pipeline
